# محدوده محصول — سامانه نظارت و هوش مدیریتی کارا

## تعریف محصول

این پروژه **ERP جدید، CRM یا سیستم ثبت اطلاعات نیست**.

یک **سامانه نظارت و تحلیلی فقط‌خواندنی** روی داده‌های Kara است که:

- هیچ سفارش، فاکتور، مشتری، کالا یا سند مالی جدیدی ثبت نمی‌کند
- داده‌های مجاز را از Kara دریافت، ذخیره، نرمال‌سازی و تحلیل می‌کند
- نتیجه را به مدیران و نیروهای فروش نمایش می‌دهد

Kara سیستم عملیاتی باقی می‌ماند. Django لایه تحلیلی است.

```
Kara (عملیاتی) → Sync → Django DB → Analytics → UI
```

## سه لایه محصول

| لایه | مخاطب | هدف |
|------|--------|-----|
| **TV Mode** | مدیریت ارشد | وضعیت کلی در چند ثانیه، نمایش تمام‌صفحه |
| **داشبورد تحلیلی** | مدیر فروش / ارشد | علت رشد/افت، فیلتر، Drill-down |
| **پنل عملکرد فردی** | ویزیتور / سرپرست | فقط داده مجاز خودشان (فاز بعد) |

صفحات جدول و گزارش (`Data Explorer`) ابزار کنترل داده هستند، نه محصول اصلی.

## سؤال‌های کسب‌وکاری

### مدیریت ارشد
- وضعیت کلی کسب‌وکار؟
- فروش، فروش خالص، سفارش، برگشت؟
- مقایسه با دوره قبل؟
- چه مواردی نیازمند توجه فوری است؟

### مدیر فروش
- بهترین/ضعیف‌ترین ویزیتور و سرپرست؟
- عملکرد شهر، منطقه، کالا، مشتری؟
- علت افت یا رشد؟

### ویزیتور / سرپرست (فاز F)
- عملکرد شخصی/تیمی، هدف، رتبه، مقایسه دوره

## خارج از محدوده (فعلاً)

- بازطراحی UI کارا
- نمایش کل ۲۴۰+ آیتم منو
- ثبت عملیات (سفارش، فاکتور، سند)
- ماژول‌های حسابداری/خزانه/انبار بدون سؤال مدیریتی مشخص
- KPI مالی حدسی (سود/زیان بدون داده معتبر)

## اصل صداقت داده

تا زمان کشف API بهای تمام‌شده و هزینه‌ها:

- از «سود واقعی» یا «زیان واقعی» استفاده نمی‌شود
- وضعیت صریح نمایش داده می‌شود: «داده سودآوری هنوز کامل نیست»
